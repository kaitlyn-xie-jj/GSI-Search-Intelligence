# GSI search SUV asset

The visual mesh and textures are version 4 of the OpenRobotics `SUV` model
downloaded from Gazebo Fuel. The original author is Nate Koenig. The asset is
distributed under CC BY 3.0; see `LICENSE`.

GSI keeps the historical entity name `yellow_search_van` for compatibility,
but detection is appearance-independent and uses the COCO vehicle classes.
The collision geometry is intentionally replaced by a simple static box.
